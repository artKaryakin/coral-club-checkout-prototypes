# Журнал прохождений

Прохождения сценариев со стенда пишутся в Google-таблицу. В браузере ничего
не хранится: прогоны со всех устройств сразу лежат в одном месте, и никто не
забудет ничего выгрузить перед тем, как почистить данные сайта.

## Как это устроено

После клика по кнопке создания заказа стенд отправляет POST в веб-приложение
Apps Script, привязанное к таблице. Скрипт дописывает строку и при первой
записи сам создаёт заголовок.

Код скрипта — в [`apps-script.gs`](apps-script.gs). Адрес веб-приложения — в
`src/stand/config/logging.ts` (или в переменной окружения сборки
`VITE_STAND_LOG_URL`, если адрес не должен попадать в репозиторий).

Отправка повторяется трижды с растущей паузой. Если все три раза мимо, экран
благодарности говорит об этом прямо, показывает строку целиком и даёт её
скопировать: модератор в этот момент ещё перед экраном, а респондент ещё в
комнате. **Экран в этом состоянии закрывать нельзя — строку больше взять
неоткуда.**

## Колонки

| Колонка | Что это |
|---|---|
| `Старт` | момент открытия чекаута, ISO |
| `Финиш` | момент клика по кнопке создания заказа, ISO |
| `Длительность, мс` | то, что сравниваем между версиями |
| `Длительность, с` | то же в секундах, чтобы не делить в таблице |
| `Страна` | `ru` · `kz` · `de` · `pl` · `cz` · `us` |
| `Тип пользователя` | `new` (книга пуста) · `saved` (восемь адресов) |
| `Версия` | `prod` · `modal` · `inline` |
| `Язык` | язык интерфейса в этом прогоне |
| `Имя`, `Фамилия`, `Почта`, `Телефон` | что респондент указал на входе |
| `Номер заказа` | номер с экрана благодарности, чтобы связать строку с записью сессии |
| `Тестовый прогон` | `да`, если профиль заполнен кнопкой «Тест-данные» |

## Что считать

Замер идёт от открытия чекаута до клика по кнопке создания заказа. Выбор
страны, заполнение профиля и выбор версии в замер не входят — это подготовка
стенда, а не сценарий.

**Тестовые прогоны из расчёта надо исключать.** Прогон кнопкой «Тест-данные»
короче любого настоящего и утянет среднее вниз — фильтруйте по колонке
`Тестовый прогон`.

Прод меряется наравне с концептами — это контрольное время, относительно
которого концепт вообще может оказаться быстрее.

## Дубликаты

Отправка повторяется при ошибке сети, а ответ веб-приложения Apps Script
прочитать нельзя: отличить «не дошло» от «дошло, но ответ потерялся» не
получится. Поэтому изредка в таблице может оказаться две одинаковые строки —
это осознанный размен: дубль виден по совпадающему времени старта и номеру
заказа, а потерянное прохождение не восстановить.
