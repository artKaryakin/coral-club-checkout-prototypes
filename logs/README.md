# Журнал прохождений

Сюда кладутся выгрузки прохождений сценариев со стенда — сырые данные к
отчётам по сессиям.

## Откуда берутся файлы

Стенд лежит на GitHub Pages, это статика: писать в репозиторий из браузера
он не может. Поэтому прохождения копятся в браузере модератора, а в репозиторий
попадают выгрузкой:

1. Открыть `#/log` (ссылка есть на первом экране стенда).
2. «Выгрузить CSV» — файл упадёт в загрузки под именем
   `stand-runs-2026-09-10-14-03-51.csv`.
3. Положить его сюда и закоммитить, лучше переименовав по сессии:
   `2026-09-10-de-modal.csv`.

Параллельно каждое прохождение уходит строкой в Google-таблицу, если задан
адрес веб-приложения (см. `apps-script.gs` и `src/stand/config/logging.ts`).
Таблица — оперативный доступ во время сессий, файлы здесь — то, что переживёт
таблицу и попадёт в отчёт.

## Колонки

| Колонка | Что это |
|---|---|
| `Старт` | момент открытия чекаута, ISO |
| `Финиш` | момент клика по кнопке создания заказа, ISO |
| `Длительность, мс` | то, что сравниваем между версиями |
| `Страна` | `ru` · `kz` · `de` · `pl` · `cz` · `us` |
| `Тип пользователя` | `new` (книга пуста) · `saved` (восемь адресов) |
| `Версия` | `prod` · `modal` · `inline` |
| `Язык` | язык интерфейса в этом прогоне |
| `Имя`, `Фамилия`, `Почта`, `Телефон` | что респондент указал на входе |
| `Номер заказа` | номер с экрана благодарности, чтобы связать строку с записью сессии |
| `Тестовый прогон` | `true`, если профиль заполнен кнопкой «Тест-данные» |
| `Отправлено в таблицу` | доехала ли строка до Google-таблицы |

## Что считать

Замер идёт от открытия чекаута до клика по кнопке создания заказа. Выбор
страны, заполнение профиля и выбор версии в замер не входят — это подготовка
стенда, а не сценарий.

**Тестовые прогоны из расчёта надо исключать.** Прогон кнопкой «Тест-данные»
короче любого настоящего и утянет среднее вниз; на экране `#/log` среднее уже
считается без них, в выгрузке фильтруйте по колонке `Тестовый прогон`.

Прод меряется наравне с концептами — это контрольное время, относительно
которого концепт вообще может оказаться быстрее.
