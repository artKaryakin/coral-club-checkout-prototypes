# Кнопки

Референс: `Buttons.png` — шкала размеров/форма кнопки (заливка, паунды, скругление).
Использовано: скругление углов у сплошных/тонированных CTA-кнопок увеличено
с `--st-global-radius-sm` (6px) до `--st-global-radius-lg` (10px) — под
пропорцию радиус/высота из референса.

Применено к (список "Primary/CTA" из инвентаря кнопок проекта):
- Cc3CheckoutSubmit.vue — `__button` («Перейти к оплате»)
- Cc3CheckoutAddressBookModal.vue — `__submit` («Выбрать»), `__new` («Новый адрес»)
- Cc3CheckoutPickupPointItem.vue — `__button` («Выбрать»)
- Cc3CheckoutPickupSelected.vue — `__button` («Выбрать другой»)
- Cc3CheckoutWallet.vue — `__apply`/`__remove` («Применить скидку»/«Убрать скидку»)
- Cc3CheckoutSummary.vue — `__promo-apply` («Применить» промокод)

Не тронуто (карточки-переключатели — другой паттерн, не «Button» из референса):
способ доставки, способ оплаты, вкладки адресов, карта/список пунктов выдачи,
карточка сохранённого адреса.

Остальные файлы этой пачки — `Arrows.png`, `Common.png`, `Contact.png` —
наборы иконок-референсов, не привязаны к конкретной задаче, использовать
точечно при добавлении новых иконок в `Cc3Icon.vue`.
